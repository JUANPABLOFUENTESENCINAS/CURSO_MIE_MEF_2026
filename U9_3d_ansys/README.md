# U9 — Elementos 3D y axisimétricos con ANSYS

**Sesiones:** 15–16 · **Evidencia:** Actividad 6 (15 %)

## Objetivo específico

Aplicar elementos finitos tridimensionales (tetraédricos, hexaédricos) y axisimétricos mediante software profesional (ANSYS) a problemas representativos de la ingeniería civil.

## Contenidos

- Sólidos tridimensionales (tetraedro de 4 nodos, hexaedro)
- Sólidos de revolución (axisimétricos)
- Aplicaciones civiles (tanques, cimentaciones, túneles)

## Actividad 6

Solución de problemas tridimensionales con ayuda de software comercial (ANSYS).

- [ ] Definición del problema civil (tanque, cimentación o túnel)
- [ ] Modelo en ANSYS (geometría, malla 3D, condiciones de contorno)
- [ ] Resultados y verificación
- [ ] Análisis de resultados (máx. 1 página, obligatorio)

## Contenido de esta carpeta

Esta unidad usa ANSYS Mechanical (versión estudiantil), no Octave. Guarda aquí el reporte de resultados, capturas del modelo, y el archivo del proyecto si el tamaño lo permite (o un enlace si es muy grande para el repositorio).

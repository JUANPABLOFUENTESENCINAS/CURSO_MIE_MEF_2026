# U7 — Formulación isoparamétrica y cuadratura de Gauss

**Sesiones:** 11–12 · **Evidencia:** Sin evidencia formal

## Objetivo específico

Generalizar la formulación de elementos finitos mediante el concepto isoparamétrico y aplicar la cuadratura de Gauss para integrar numéricamente las matrices elementales.

## Contenidos

- Formulación isoparamétrica
- Transformación y Jacobiano
- Cuadratura de Gauss

## Contenido de esta carpeta

Sugerencia de script: `cuadratura_gauss.m` — función genérica de integración de Gauss-Legendre (1D y 2D) para verificar el cálculo de matrices elementales isoparamétricas, reutilizable desde U6/U9. Agrega aquí también los apuntes de la deducción del Jacobiano.
